# 分诊标签

| 角色 | 标签              | 含义                                  |
| ---- | ----------------- | ------------------------------------- |
| 类别 | `bug`             | 故障或行为异常                        |
| 类别 | `enhancement`     | 新功能或改进，文档也归这类            |
| 状态 | `needs-triage`    | 待维护者评估                          |
| 状态 | `needs-info`      | 等提问人补充信息                      |
| 状态 | `ready-for-agent` | 规格完整，agent 可以独立完成          |
| 状态 | `ready-for-human` | 需要人工决策或外部凭据                |
| 状态 | `wontfix`         | 不处理；重复或无效的 issue 也用它关闭 |

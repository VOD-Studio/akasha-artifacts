# Akasha UED 工作区改版

> 本文记录工作区的已交付基础与交互约定。完整首版范围、验收和后续 Artifacts／Figma 产品线见 [Design 产品 PRD](../prd/design-v1.md)；引擎建设历史见 [#5](https://github.com/VOD-Studio/akasha-artifacts/issues/5)。

## 已实现的画布基础

[#53](https://github.com/VOD-Studio/akasha-artifacts/issues/53) 已实现独立的多页面、多画板画布：可以搜索页面和画板、复制页面链接、选择画板、平移缩放，并保留视角。从历史版本复制的页面链接会固定到该版本。页面导航、画板边界和批注叠层由外壳管理；只有画板里的网页内容在各自的隔离 iframe 中渲染。普通 HTML／React 制品仍使用一个默认画板。

滚轮和触控板滚动沿各轴平移；抓手或空格拖动画布。用 Ctrl／⌘ 加滚轮或双指捏合以指针为锚点缩放，工具栏也可直接调整倍率。

触屏总览中，点画板或对象可选中，单指滑动可平移，双指以中点缩放。长按文字后松手可编辑；长按再拖可移动可写画板。捏合接管未提交的拖动，松开剩下的一指不会保存或重新选板。进入交互预览后，点击和滚动交给原型。

[#55](https://github.com/VOD-Studio/akasha-artifacts/issues/55) 在头版本的页面导航提供新建、重命名和删除。改名保留定位标识；删除需确认直属画板范围，共享画板及旧版本不变。保存按基准版本检查并发修改。

[#54](https://github.com/VOD-Studio/akasha-artifacts/issues/54) 的制品库共用搜索、项目／类型筛选、排序和卡片／列表工具栏。`⌘K / Ctrl+K` 聚焦搜索框；返回时还原筛选与滚动。卡片只为视口里的制品按授权版本生成首个画板的静态 PNG，同一时间最多一个临时隔离沙盒，完成即移除；不能生成时显示标题和类型。封面缓存在当前页面会话，没有可枚举的服务端图片地址。

作品库和工作区顶栏提供「界面语言」。默认简体中文，可切换为英语、德语或阿拉伯语；偏好保存在当前浏览器，不写入作品或分享链接。切换不重载画布，不清除选区、未发送的批注或代码草稿。日期、数量、复数和读屏提示随语言变化；作者标题、正文、代码和版本标识保持原样。阿拉伯语中导航和抽屉换到逻辑起始侧／末端，画板坐标、媒体时间和作品内容不翻转。

[#56](https://github.com/VOD-Studio/akasha-artifacts/issues/56) 支持从画板标题旁展开单张画板，保留其固有视口，可适应窗口、填充宽度、调整倍率或滚动。检测到可用控件时提供「播放」；原型在独立沙盒中接收输入。退出后恢复原视图、相机和选区。

[#57](https://github.com/VOD-Studio/akasha-artifacts/issues/57) 的检查器可在无选区时打开，从页面、画板和图层树定位画布。选择工具单击板头选整板，单击已显示的画稿选命中图层，不会触发原型控件。属性显示画板视口和图层尺寸；源码只在有唯一静态位置时定位，否则该图层只读，仍可批注。模板运行参数单列「调参」，不进入源码版本；固定版本的调参只读。检查器和批注抽屉互斥，开合不改变画布尺寸。

[#113](https://github.com/VOD-Studio/akasha-artifacts/issues/113) 区分「画板参数」的会话预览和发布。改值、重置或换板都不写版本。在可写头版本选择「应用参数…」，默认选本板，也可改选其他画板；目标画板须有相同标识的参数，类型与取值兼容，且默认值确实会改变。确认「发布新版本」后，所选画板一次写入，可撤销；旧版分享和离线导出仍读取旧默认值。分享访客和固定版本只能预览，不能发布这些调整。

选择「请 Agent 应用」只投递给该作品已绑定、可用的本机会话；受理不代表发布。只有 Agent 在原基准版本调用专用工具后，对话中才会出现新版本链接与实际更改的画板。基准过期必须重新选择，不会自动合并或重复提交。

[#58](https://github.com/VOD-Studio/akasha-artifacts/issues/58) 的画板管理支持添加空板、复制和确认删除。在画板标题旁的「设置画板」填写位置和固有视口尺寸，一次应用生成一个新版本；旧版没有绝对位置时继续使用网格排列。应用时校验基准版本，保存失败可下载未保存源码，不会覆盖其他作者的新版本。

拖动画板标题可移动；选中画板后拖右下角可调整视口。拖动只预览，松手才保存。相机控制旁可撤销和重做本会话最近 24 次编辑；画布内也可用 `⌘/Ctrl+Z` 和 `⌘/Ctrl+Shift+Z`，不会接管输入框。若头版本已被其他操作推进，不重放旧快照。

按住 `Shift` 选择多个画板，在「排列画板」中按选区边缘或中心对齐，也可组合、取消组合。同一页面上的组成员联动选取和移动；对齐或移动组选区只提交一个新版本。布局组合与评审分组无关。

在「检查器」选中原生图层后，可按画板坐标调整其位置或大小；在图层树按 `Shift` 多选可对齐、组合同一画板中的图层。改变主图层的位置会一起移动选区，宽高只作用于主图层。原生图层写入画板的 `designLayers`，与普通 HTML 或 React 的运行节点独立，并使用相同的历史与保存冲突规则。普通运行节点不提供布局编辑。

底栏按选择、抓手、文本、画板、便签、铅笔、形状和批注排列。铅笔记录拖动轨迹；同组钢笔逐点放置节点，双击或 Enter 完成、Esc 放弃。有编辑权限时，形状菜单可选矩形或椭圆。新对象可在图层树定位、在检查器移动／复制／删除，也可撤销和重做。

在总览用「添加文本／便签」放置对象，完成文字后发布一次。双击已有文字或在检查器选择「编辑文字」可就地输入，不启动原型。普通 HTML／React 只改具有唯一静态源码位置的字面量文字；运行时生成的元素只提供批注入口。`⌘/Ctrl+Enter` 保存，输入框中的空格、删除和撤销保留原生语义。

起稿等待时回库用「继续设计会话」打开原请求，不再发送一次。

[#64](https://github.com/VOD-Studio/akasha-artifacts/issues/64) 顶栏和画板各自打开「导出设计」，分别预选整份设计或单张画板。PNG 保留固有视口；整份 PDF 按页面与画板顺序排列，共享画板只输出一次。确认时重新验证所选固定版本的读取权限。导出不包含工具、批注、运行存储或未保存的草稿，任一画板无法渲染则不下载半成品。

[#114](https://github.com/VOD-Studio/akasha-artifacts/issues/114) 在画板「属性 → 打印与辅助线」选择「固定」或「流式」。固定沿用画板宽高，只有一页；流式可选 A4 或 Letter，按纸宽排版，长内容连续分页。在导出窗口选择 PDF，打开「打印预览」可逐页查看；下载的是刚预览的文件。纸型和辅助线可一起保存，撤销一次还原。缩放菜单或 `Shift+G` 只切换当前选中画板的辅助线，不发版，也不改变 PNG、打印预览或 PDF 的正文。

新增批注默认只供讨论；「同时发送给 Agent」为逐条选择。评审轮次中的草稿保存后可在工作区查看，勾选投递的批注要等提交本轮才可被 Agent 消费。

未发送的正文、选区、版本和投递勾选留在当前浏览器标签页。刷新或切换工具可恢复；头版本推进时可回到原版本继续，草稿不会改挂到另一个画板。原轮次已变更时，须显式转成独立批注，且重新选择是否投递。

先选对象，再打开「批注」可添加带定位的批注；也可不选对象，直接查看全部线程。图钉直达原讨论；侧栏可筛选当前页和解决状态，不改变画布尺寸。旧版批注有「回 vN 定位」，不会套用到新版或同名元素。回复可刷新后继续撰写，人工解决与重新打开不影响 Agent 回执。

制品标题菜单提供普通定位链接、重命名、重新加载及整份源码、版本、导出和分享入口。重命名只更新展示名；链接、所有历史快照和原生源文件不变。重新加载重读服务端数据，不重置画布或未发草稿。

收藏只写当前用户的索引；制品库的「仅收藏」与原有的项目、类型、标题搜索一起筛选，不改变其他用户的排序或权限。存储用量读取当前制品的共享和当前用户自己的运行存储，展示序列化字节及配额，不返回键值或其他用户的用量。

[#66](https://github.com/VOD-Studio/akasha-artifacts/issues/66) 从制品标题菜单移交整份设计；从检查器移交已保存的画板或选中图层。复制交接后粘贴到已配置 Akasha MCP 的同一项目，`artifact_read_handoff` 按交接时的快照读取授权源码和结构，不跟随头版本。交接只包含标识，不授予读取权限、不启动会话。

[#63](https://github.com/VOD-Studio/akasha-artifacts/issues/63) 自托管 Hub 的制品所有者可签发「仅查看」「可批注」「可编辑头版本」链接。链接可跟随头版本、固定快照，或定位到固定版本的交互画板；打开链接不会自动播放原型。持链接者只能操作该制品的授权范围，不能管理制品、投递给 Agent 或同步运行存储；原有团队身份权限不变。普通定位链接不授予访问权限。

[#68](https://github.com/VOD-Studio/akasha-artifacts/issues/68) 标题菜单可把当前固定版本复制到有权限的项目，创建私有制品及独立链接，不复制评审、分享、会话和运行存储。移动不改变原 `publicId`、版本、批注或既有授权，只可在同一实例的授权项目内进行。自托管 Hub 只允许同一所有者的项目间移动；目标 slug 已占用则拒绝，不会覆盖。原生文件模式只绑定一个项目，跨项目需使用 SQLite Daemon 或自托管 Hub。

[#69](https://github.com/VOD-Studio/akasha-artifacts/issues/69) 撤下会隐藏制品及其固定版本、收藏项、讨论和实时内容，但不删除版本、反馈或原生文件。维护者在库的「已撤下」恢复后，原书签按原可见性恢复；所有已撤销的签名仍无效。原生文件在撤下期间不重新导入为活动制品。

[#65](https://github.com/VOD-Studio/akasha-artifacts/issues/65) 同一导出面板可将单张画板导出为 HTML ZIP，或将整份设计导出为独立 HTML。离线打开即可与原型交互，无需 Daemon；整份设计保留已声明的跨画板流程。离线沙盒复用 HTML、React 和原生图层等现有渲染。导出只读取指定版本的授权内容，不包含反馈、会话、登录信息或运行存储。外链资源需以内嵌 `data:` 提供；预检失败不下载部分产物。交互时才出现的动态依赖若不可用，离线页会报告错误。

[#118](https://github.com/VOD-Studio/akasha-artifacts/issues/118) 选择「整份作品 → 离线 ZIP」会下载该版本的文件包。完整解压后打开根目录的 `index.html`，不需要启动本地服务；保留相邻的 `assets/` 文件夹。可按原顺序切换页面和画板；空页不借用其他页的内容，共享板在所属页均可打开，已声明的流程可跳到另一页。离线预览沿用导出时的界面语言，不翻译作者内容。单板 ZIP 仍只含所选画板，选区仍只导出 PDF。

本机托管 Codex 会话由终端显式授权：先登录 `codex`，再运行 `akasha agent connect --project <项目路径>`；可用 `akasha agent design --project <项目路径> --prompt '<需求>'` 启动真实会话并发布。`akasha agent disconnect --project <项目路径>` 撤掉执行授权，保留历史；Daemon 重启后须重新连接。未通过此入口实际发布的旧制品没有可推断的会话绑定。自托管 Hub 和签名分享不会驱动本机 CLI。

[#61](https://github.com/VOD-Studio/akasha-artifacts/issues/61) 工作区顶栏「Agent 对话」与检查器选中对象后的「问 Agent」打开同一个发布会话。对象引用保留制品、版本、画板和对象标识。桌面并列显示，窄屏可返回画布；未发送文字单独保存在当前标签页。新版本按唯一 `data-ak-block` 或原生图层标识重新定位；不会拿旧选择器猜测新版对象。CLI 最终文字和这一轮实际发布的版本分别呈现，离线不排队。

[#62](https://github.com/VOD-Studio/akasha-artifacts/issues/62) 本机制品库的「新建设计」先选择已登记项目和获授权的 Codex，再发送需求。无连接时可保留标签页草稿并按提示在终端接通；等待中关闭和重开仍跟踪原会话，不会重发。只有该会话实际写入第一版才显示「打开已发布设计」，失败或仅回复不生成占位卡片。原会话不可恢复时可明确放弃跟踪并重选，需求草稿不丢失，也不会自动发送。

## 改版前的问题

- [制品库](../../apps/web/src/widgets/LibraryShell/LibraryShell.tsx)把项目登记、活跃／休眠、类型和 `slug` 放在第一屏；人只能读元数据，不能通过画面认出要看的设计。快速跳转和页面搜索各有一套入口。
- #53 之前，[工作区](../../apps/web/src/widgets/ArtifactWorkspace/ArtifactWorkspace.tsx)只把一个固定 1280 × 800 的沙盒当画板，并排方案也在同一个沙盒里排成卡片。打开制品、定位画板和预览原型没有独立入口。
- [检查抽屉](../../apps/web/src/widgets/InspectorPanel/InspectorPanel.tsx)同时放属性、编辑器式表单、批准／请求修改和反馈流水。看到一个元素想留句话，却先进入一个综合面板；审阅时很难确认一句话针对哪个画板与版本、何时通知 Agent。

## 对齐什么

以截图所示的 **Claude Artifacts 中的 Design 工作区**为参考，不是传统聊天旁的 HTML 预览。根据 [Claude Design 官方使用指南](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)、[官方原型教程](https://academy.claude.com/tutorials/using-claude-design-for-prototypes-and-ux)、[键盘与批注说明](https://support.claude.com/en/articles/17457950-use-artifacts-with-a-keyboard-or-screen-reader)及[分享权限](https://support.claude.com/en/articles/9547008-publish-and-share-artifacts)，首期以网页版设计工作区可完成的任务为验收：

对齐的是用户能完成的操作，不要求菜单位置、图标或分栏样式一致。能减少切换、误操作或查找成本时，采用 Akasha 自己的布局与组件。

- 在同一份设计的不同页面间切换；每页能摆放多个独立、可选的画板，拖动、缩放、适应全页或选区。一个画板可以容纳多个图层，而不是一个大 iframe 里的卡片。
- 默认选择、检查和编辑；只有显式点击「播放」／画板的预览入口才操作原型。支持编辑文字、拖放、调整尺寸、对齐、分组、复制、删除、撤销／重做；支持添加画板、文本、便签、基本图形和画笔标记。属性随选中的画板或图层变化。键盘能进入、退出和选取已有对象。
- 对画板／图层发起批注、看回复、解决线程；可选择只留给人，或同时发送为 Agent 修改请求。能打开与发布 Agent 的对话，对整份设计提出要求，拿到真实响应与新版本。
- 分享可查看、可批注、可编辑的链接；支持按画板导出 PNG、PDF、HTML（ZIP），以及导出整份设计的 PDF／可交互 HTML、交给 CLI Agent 继续实现。权限和导出都是真动作，不出现仅作摆设的按钮。

沿用 Akasha 的版本快照、反馈轮次、沙盒隔离和本机优先。异步授权编辑不等于多人共编；首版团队共编走 [#101 Docker Hub](https://github.com/VOD-Studio/akasha-artifacts/issues/101)，与 [#29 可选 Workers 部署](https://github.com/VOD-Studio/akasha-artifacts/issues/29) 无关。首版包括团队设计系统、外部目的地交付及移动端的使用流程；不另做 Claude 模型、原生客户端壳或账号计费。

## 全站界面

### 制品库：按作品找，不按后台字段找

- 制品库同时列出设计和其他已发布制品。项目、类型、收藏和排序与搜索同组；`⌘K / Ctrl+K` 聚焦搜索。卡片显示当前授权版本的封面，列表补充别名与版本号。
- 卡片与列表的标题都是制品链接，可在新标签页打开。回库保留搜索、筛选、显示方式和滚动位置。项目登记与已撤下制品从管理菜单打开。
- 本机提供「新建设计」，选择项目和已授权 Agent 后提交；只在真实发布后打开设计。Hub 库不显示不能派发的本机创作入口。
- 加载时用骨架占位；未找到制品可清除筛选；读取失败可重试。本机空库提供 Agent 接入链接。

### 设计工作区：低噪声外壳，画面是主体

- 宽屏顶栏单行，窄屏按组折行。起始侧是返回作品库、作品标题和版本；另一侧是会话、检查器、批注与分享。只有有管理权的 Hub 用户可从顶栏创建分享链接；普通定位链接、整份导出、源码和版本对比仍在标题菜单。
- 画布铺满顶栏下的工作区。页面选择在顶部起始侧，播放、适应和倍率在另一侧；绘制工具靠下居中。窄窗分行，不要求用户横向滚动整个工作区。
- 起始侧导航按页面分组。页名旁显示画板总数（含共享画板，搜索不改变计数）；当前页面用页标识，选中画板用勾选标记。点击页名保留该页的视角和选区，点击画板直接定位。「新建页面」属于工作区；复制定位链接、重命名和删除归入各页的「更多」菜单，不切换当前页。固定版本和仅查看角色只能导航、复制链接；链接不额外授予访问权限。
- 画板标题在画板外，边界不随工具开合跳动。选中后只在画板轮廓和操作柄上用强调色；悬停不是选中。单击选对象，进入画板后才能选图层；双击文字进入文字编辑，不隐式播放。空格抓手不接管输入框的按键；缩放对准光标，适应全页或选区。
- 画板标题旁提供「展开画板」与单板导出；可交互画板另有「播放原型」。在画布顶栏的「播放」菜单也可按静态、动画或原型分组找到本页画板。展开支持 Fit（适应窗口）、Fill（填充宽度）、倍率切换和单板导出；它不是试玩入口，返回时保持原选区。
- 同一业务流程的页面、不同状态或设计备选放在同一页画布上，按各自尺寸并排比较，不要求每张设计图单独翻页。先加载当前视口的画板内容，屏外资源不能阻塞选择、平移和缩放。打开指定画板的链接仍定位该画板；普通 HTML／React 制品可继续只用一张默认画板。画板的位置和尺寸随设计保存，个人视角不入版本。
- 右侧检查器可主动打开，无选区也能浏览画板与图层树；从树定位或从画布选择，双方同步。有选区时区分「属性」「源码」「调参」：编辑布局／图层、定位关联源码、调整制品声明的运行参数。一次拖放、尺寸调整或编辑完成后自动保存，不会随鼠标移动不断发布新版本。使用基准版本防止人和 Agent 的保存相互覆盖；浏览旧版只读，可返回最新。

### 原型预览

- `presentation.animation` 与 `presentation.interactive` 独立声明，可同时为 `true`。显式 `false` 关闭对应能力；未声明的旧稿按可控时间轴和真实控件判断，装饰按钮或音频不起作用。总览只循环可见板上的静音动效，最多 6 板；可以手动暂停，也尊重浏览器后台和减弱动态效果设置。不能受时间轴控制的动图在总览显示静帧。
- 在交互画板上选择「播放原型」进入交互预览。画布的编辑手柄隐藏，用户按原型定义的流程操作。分享链接可指定画板与版本。
- Esc 退出后恢复原页面、视角、缩放、选区和进入前的焦点。预览中的表单输入不写入设计，未提交的批注保留。原型出错时，只在相应画板报告。嵌入 `data:` 或 `blob:` 的音视频只有在试玩中由人手动启动，进入试玩不会自动播放。
- 在 `artboard` 中，设 `flows: [{ "from": "home", "to": "slots" }]` 声明转换边，并在 `home` 的按钮或表单上写 `data-ak-next="slots"`。固定版本只使用自己的转换边；`showFlows: false` 只隐藏画布连线。可到达明确标为静态的确认画板，但该画板不接收原型输入。表单保留浏览器约束校验，不会向外提交。
- HTML、React 和 `artboard` 中的原型控件支持交互预览。工程模板仍在原视图提供浏览、图表和行内批注。

### 批注与 Agent 对话：分开入口，保留上下文

- 批注使用 `@akasha/ui/sheet`，保持 `modal={false}`，从逻辑末端滑出，无蒙层。画布工具负责新增定位批注，顶栏「批注」打开全部线程及展示数量；列表可筛选并定位到目标页面和画板。点击现有图钉直接打开该线程，不另起浮层。开关抽屉不缩窄画布，也不触发自动适应。
- 批注显示「页面／画板 · 对象 · 版本」而不把源码定位符当主要标签。普通批注的「同时发送给 Agent」明确控制投递；不勾选仍保存给人看，不唤醒 Agent。评审轮次中明确显示「草稿」，只在提交本轮后送达。不再存在的目标仍可打开原版本，不把评论挂到其他对象。
- 本机会话默认收起。展开后桌面是左会话、右画布；窄屏切到会话，画布实例不重建。返回时保留相机、选区与草稿，焦点还给会话按钮。「问 Agent」可附上当前选区；Hub 与签名分享不显示本机会话入口。

### 制品操作与交付

- 标题菜单承载整份制品的操作：复制制品链接、导出、打开会话／移交 Agent、收藏、重命名、复制、移动、重新加载、存储用量和删除。作用域需明确：例如复制制品得到新标识，重命名不使源链接失效；已有授权的定位链接与创建新的签名分享分开。
- 板头默认导出该板，作品菜单默认导出整份作品。单板 PNG 可选 1× 或 2×，像素尺寸以固定版本的画板为准，不随屏幕或画布缩放。选区 PDF 只含打开面板时选中的本页画板，先按当时画布的排列列出页序：从上到下、同高从左到右，重叠同位时沿用页面里的先后顺序。调整每行列数会改变自动排列画板的页序，不改变画板内容。整份 PDF 仍按作品的页面与画板顺序。任一所选板失败不下载残缺文件。
- 导出的 HTML 可打开并操作指定版本的原型。「移交给 Agent」携带制品、版本与选区，而非仅提供通用链接。
- 截图显示了 `Turn into`、`Move to…`、`Storage` 和 `Give feedback` 的入口，未展示后续选项。转换目标、移动的目标集合、存储可管理范围和反馈接收方需核实。

## 视觉约束

库页用宽留白和内容缩略图，工作区用黑白灰区分画布、工具面和主操作。选中与焦点用描边和明暗区分；成功、警告和错误保留各自的状态色。大区块只用细线分隔，正文 14px，辅助信息不小于 12px。制品内的配色和字体由作品自己决定。

### 组件

- 工作台统一复用 `@akasha/ui`：批注和检查器用 `Sheet`；分享用 `Modal`；按钮、菜单、提示、输入和快捷搜索使用现有基础组件与主题令牌。Agent 会话区按工作区布局组合，不套成第三个右侧抽屉。Claude 只作为交互参考，不复制它的组件，不引入另一套 UI 库。
- 画板、缩放工具条和批注线程留在 `apps/web` 按业务组合，不另造一套基础控件。只有现有组件缺少可复用能力时，才在 `packages/ui` 补齐，沿用现有键盘与焦点行为。

## 用真实任务验收

1. 在制品库根据内容找到「茶席预约」。筛选项目后打开，回库仍停在原筛选和滚动位置；从 Agent 链接打开不经过库。
2. 在同一版本的「预约流程」页同时看到首页、选择时段、确认和移动端。复制页面链接后可直达该页；切到另一页再回来，视角还在。无选区时可从检查器的树找到画板；调整画板位置和文字后刷新，已保存的设计仍在，旧版本不变。
3. 聚焦到「选择时段」后可在填充和完整显示之间切换，仍不会触发原型。点击「播放」能完成预约的模拟流程，退出后返回原画板与倍率。
4. 针对 14:30 留一条不通知 Agent 的团队批注；另发一条要求 Agent 修改文字的批注。分别看到可回复的线程和实际 Agent 回应／新版；已有选区、视角与未提交评审不被刷新清空。
5. 分享同一个版本，分别用查看、评论和编辑权限打开；验证功能权限不同。把画板交给 CLI Agent 能还原设计上下文，不依赖截图猜测。

验收分别覆盖单板与多板、画布浏览与原型预览、批注草稿与投递，以及首次进入和返回后的状态恢复。
